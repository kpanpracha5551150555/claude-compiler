# SBAC Compiler

เว็บเขียนและรัน SQL ออนไลน์ หน้าตาแบบ OneCompiler (SQL Server) ที่ต่อยอดด้วย **แม่แบบ**, **บทเรียน**, **หน้าตาราง** และ **แบบฝึกหัด**
ทำงานในเบราว์เซอร์ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์ฐานข้อมูล

## ความสามารถ

| หน้า | รายละเอียด |
|---|---|
| **คอมไพเลอร์** | หลายไฟล์ในแท็บ · **ปุ่ม Run รันเฉพาะแท็บที่เปิดอยู่** (ชื่อไฟล์แสดงบนปุ่ม) · รันเฉพาะส่วนที่เลือก · รันทุกแท็บตามลำดับ · ทุกแท็บใช้ฐานข้อมูลเดียวกัน · Reset DB · โหมด "เริ่มใหม่ทุกครั้ง" · ค้นหา/แทนที่ · แนะนำชื่อตาราง/คอลัมน์ · ประวัติการรัน · บันทึกโปรเจกต์ · แชร์ลิงก์ · ธีมสว่าง/มืด |
| **แม่แบบ** | โปรเจกต์ตั้งต้น 7 แบบ (ร้านค้าออนไลน์, ทวีป, โรงเรียน, ร้านสะดวกซื้อ, HR, ห้องสมุด, ว่างเปล่า) + โค้ดสำเร็จรูป 14 แบบ |
| **บทเรียน** | 16 บท ภาษาไทย ตั้งแต่ SELECT ถึง CTE/Window function · ตัวอย่างแก้และรันได้ในหน้า · โจทย์ท้ายบทตรวจอัตโนมัติ · ติดตามความคืบหน้า |
| **ตาราง** | ดูทุกตารางในฐานข้อมูลของ workspace · ข้อมูล/โครงสร้าง/Foreign key/คำสั่ง SQL · ค้นหา เรียง แบ่งหน้า · นำเข้า-ส่งออก CSV |
| **แบบฝึกหัด** | 25 ข้อ ระดับ ง่าย/ปานกลาง/ยาก · ตรวจโดยเทียบผลลัพธ์กับเฉลยบนฐานข้อมูลใหม่ทุกครั้ง · คำใบ้ · เฉลย · ผลลัพธ์ที่ควรได้ |

### ภาษา SQL ที่รองรับ

ใช้ SQLite (sql.js / WebAssembly) เป็นเครื่องรัน พร้อมชั้นแปลภาษาให้เขียนแบบ **SQL Server (T-SQL)** หรือ **MySQL** ได้ เช่น
`IDENTITY(1,1)`, `GO`, `TOP n`, `N'ข้อความ'`, `PRINT`, `DECLARE @x` / `SET @x`, ต่อสตริงด้วย `+`, `GETDATE()`, `LEN()`, `ISNULL()`,
`DATEDIFF/DATEADD/DATEPART`, `CONVERT`, `OFFSET … FETCH`, `SELECT … INTO #temp`, `INFORMATION_SCHEMA`, `sp_help`,
คำสั่งที่ไม่มี `;` คั่น และการเปรียบเทียบข้อความแบบไม่สนตัวพิมพ์เล็ก-ใหญ่ · MySQL: `AUTO_INCREMENT`, `SHOW TABLES`, `DESCRIBE`, `NOW()` ฯลฯ

## วิธีรัน

ไม่ต้องติดตั้งอะไร — เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น

```bash
python -m http.server 5173
```

แล้วเปิด http://localhost:5173 (ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลด CodeMirror และ sql.js จาก cdnjs)
หรือเปิดผ่าน GitHub Pages ได้ทันที

## โครงสร้างโปรเจกต์

```
index.html            โครงหน้า
css/app.css           ธีมและ layout
js/util.js            helper UI (modal, toast, ตารางผลลัพธ์, CSV, แชร์ลิงก์)
js/store.js           บันทึกลง localStorage
js/dialects.js        แปลง T-SQL / MySQL → SQLite
js/engine.js          ตัวรัน SQL, schema, ตัวตรวจคำตอบ
js/workspace.js       workspace ปัจจุบัน (ไฟล์ + ฐานข้อมูล)
js/data/*.js          ชุดข้อมูล แม่แบบ บทเรียน แบบฝึกหัด
js/pages/*.js         หน้า Compiler / แม่แบบ / บทเรียน / ตาราง / แบบฝึกหัด
js/app.js             router, ธีม, เริ่มระบบ
```

แผนงานและเฟสถัดไปอยู่ใน [PLAN.md](PLAN.md)
